Data changes over time

The CDC/ATSDR SVI databases have changed over time, so we caution against comparing the different versions of our databases for several reasons:

  • We created the percentile scores included in each database by ranking census tracts relative to other census tracts in the same year. Therefore, percentile scores of different tracts in different years are not comparable.
  • Starting in 2010, we use the 5-year ACS data, so the databases may have data sampled from overlapping years.
  • We have made some changes to the CDC/ATSDR SVI over time because data from the U.S. Census Bureau changed or because we decided updates were needed to keep up with the latest research on the topic.
  • The U.S. Census Bureau redraws many census tract boundaries in each decennial year, meaning that census tracts included in the 2000 CDC/ATSDR SVI database are not equivalent to the census tracts included in the 2010, 2014, 2016, and 2018 CDC/ATSDR SVI databases (2020 and 2022 CDC/ATSDR SVI databases also contain different tracts). Even in cases where the census tract does not undergo a name change, modifications to the census tract geographic boundary may impact comparability over time.

Data correction

Data values for MP_CROWD (Percentage of occupied housing units with more people than rooms estimate MOE) in the 2022 SVI dataset were updated on 12/11/24. This update does not impact the SVI rankings, interactive map, or the county map series and those remain correct and unchanged. The MP_CROWD variable was previously using Housing Units in the denominator instead of Occupied Housing Units and thus the values after release on 5/21/24 and before 12/11/24 were incorrect.

Data values for Housing Burden and Overall SVI in the 2020 SVI dataset have been updated. These variables were previously using E_HBURD instead of EP_HBURD in the calculation and thus the values after release on 10/27/22 and before 12/22/22 were incorrect.

Data values for Income and Overall SVI in the 2000 SVI dataset have been updated. The income variable was previously inversely ranked, which also impacted the Overall SVI calculation. These data were recreated in 2021 to be added to the interactive map, and thus the values after release on 10/27/22 and before 1/15/26 were incorrect.
